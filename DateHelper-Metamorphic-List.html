DateHelper Metamorphic Relations List

Relation # Category Description
1 Symmetric Inputing a date in format A and changing it to B, then taking B and changing it to A will result in the original date in format A exactly
2 Symmetric The extracted date of two different datetimes, where the date is the same but the time is different, will be identical. (get date only). This also applies to ANY datetime format, meaning changing the datetime format and then doing this again should result in the identical original result
3 Symmetric prettyifyDate() should return the same output for the same date in both its long and String formats.
4 Symmetric getDateOnly() should return the same output for the same date in both its long and String formats.
4 Symmetric getDateAndTime() should return the same output for the same date in both its long and String formats.
6 Symmetric call get today to get date D. Calling get today with time, and then calling getDateOnly (if possible) on the result to get D'. D should = D'.
7 Change Two different dates / datetimes in the same format will differ even when converted to the same format
199 Change Two different dates / datetimes in the same format F will differ even when converted to the same format G.
